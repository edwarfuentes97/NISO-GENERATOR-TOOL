# Archivo — diseño HTML legacy (no se suben imágenes a GitHub)

Contiene el export antiguo de Claude Design, usado solo si corres `npm run board`.

**En GitHub** van los archivos `.html` y `.js`. Las carpetas `assets/`, `uploads/`, `screenshots/`, etc. con fotos y PNG **no se versionan** (quedan en tu máquina si ya las tenías).

Si clonas el repo en otra PC y necesitas el board completo, copia esas carpetas desde un backup o genera las piezas con los generadores de `src/` en lugar del board.
